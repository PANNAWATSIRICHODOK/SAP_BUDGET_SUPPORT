8. บั๊ก Concurrency Risk: การรัน PK ภายใน Loop

มีการใช้ SELECT MAX("DocEntry")+1 ภายใน Loop สำหรับการทำ INSERT เสี่ยงต่อการเกิด Primary Key Violation เมื่อใช้งานพร้อมกันหลายคน.

ไฟล์: NDBS_BUDGET_AP (บรรทัด 618-627)
BAmount = -:BAmount; Select IFNULL(MAX("DocEntry")+1,1) into AutoKey From "NDBS_BGC_OBPE"; INSERT INTO "NDBS_BGC_OBPE" ("DocEntry","BudgetGroup" ,"BudgetYear",...) VALUES (:AutoKey,:BCode,TO_NVARCHAR(:BYear),...); Select IFNULL(MAX("DocEntry")+1,1) into AutoKey From "NDBS_BGC_OBPE"; -- มีการเรียก MAX ซ้ำๆ ภายใน Loop เดิม เสี่ยงต่อ Index ไม่ทันสมัย
