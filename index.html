BUG_01 // PR_VALIDATION_NOT_ROUTED
ต้องแก้

1. PR Budget Year validation อยู่ใน Control แต่ไม่ได้ถูกเรียก

NDBS_BUDGET_CONTROL มี block ตรวจ PR line OcrCode และ U_NDBS_BudgetYear แต่ SBO_SP_TransactionNotification ไม่ได้ส่ง object type 1470000113 เข้า Control.

ผลกระทบ: ถ้าต้องบังคับ Budget Year ที่ PR จริง เงื่อนไขนี้จะไม่ทำงานจาก store ล่าสุด แม้ code ตรวจจะมีอยู่แล้ว.

ควรแก้: ให้ PR เข้าเฉพาะ validation path โดยไม่เรียกสร้าง Budget movement ของ PR.

ไฟล์: SBO_SP_TransactionNotification.sql + NDBS_BUDGET_CONTROL.sql
IF :object_type In ('22','21','20','18','19','30') then call NDBS_BUDGET_CONTROL (...); end if; IF :object_type ='1470000113' Then ... IFNULL(t1."U_NDBS_BudgetYear",0)=0 ... End If;
BUG_02 // ACTUAL_OBJECTS_NOT_ROUTED
ต้องแก้

2. Actual จาก Incoming / Outgoing / GI / GR ยังไม่เข้า Budget flow

NDBS_BUDGET_JE รองรับ TransType 24,46,59,60 แล้ว แต่ Transaction Notification และ Control เรียก JE เฉพาะ object_type = 30.

ผลกระทบ: เอกสาร Incoming, Outgoing, Goods Receipt, Goods Issue ที่ควรไปเป็น Actual อาจไม่เข้า Monitor.

ควรแก้: เพิ่ม routing สำหรับ object 24,46,59,60 และ map key ให้ JE ได้ TransId ที่ถูกต้อง.

ไฟล์: SBO_SP_TransactionNotification.sql + NDBS_BUDGET_CONTROL.sql + NDBS_BUDGET_JE.sql
IF :object_type In ('22','21','20','18','19','30') then call NDBS_BUDGET_CONTROL (...); end if; elseif ( :object_type = '30') then Call NDBS_BUDGET_JE (...); T0."TransType" IN ('30','46','24','59','60')
RISK_01 // FULL_RECALC_STILL_USED
performance

3. มี Touched update procedure แต่ runtime ยังใช้ Full recalculation

Store ล่าสุดมี NDBS_UpdateTouchedBudgetAmount สำหรับ recalc เฉพาะงบที่โดนแตะ แต่ NDBS_BUDGET_CONTROL ยังเรียก NDBS_UpdateAllBudgetAmount ทุกครั้งหลังผ่าน budget flow.

ผลกระทบ: ความถูกต้องอาจยังได้ แต่มีความเสี่ยงเรื่อง performance เพราะทุก transaction ไปคำนวณยอดทั้งหมด.

ควรทำ: เปลี่ยน runtime ไปใช้ touched refresh หรือให้ vendor ยืนยันเหตุผลที่ยังต้อง full refresh.

ไฟล์: NDBS_BUDGET_CONTROL.sql + NDBS_UpdateTouchedBudgetAmount.sql + NDBS_UpdateAllBudgetAmount.sql
DELETE FROM NDBS_BGC_OBPE WHERE "Amount"=0; DELETE FROM NDBS_BGC_OBDE WHERE "Amount"=0; call NDBS_UpdateAllBudgetAmount; CREATE PROCEDURE NDBS_UpdateTouchedBudgetAmount (...)
